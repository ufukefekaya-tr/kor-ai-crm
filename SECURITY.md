# Security

The default server is local to your computer and has no multi-user authentication.
Use a reviewed authenticated reverse proxy and TLS before any remote deployment.
Customer contacts, visit notes and locations are personal data: manage your own
access, retention, consent and backups. Never commit runtime databases or `.env`.

Agent chat defaults to deterministic local demonstrations. Explicitly enabling
a provider sends the entered message and a bounded CRM summary to that provider;
review your data permissions before doing so. Agents cannot write records or
execute shell commands. No outbound notifications or background jobs are enabled.

Report vulnerabilities privately through GitHub private vulnerability reporting
when enabled. Include only synthetic reproduction data.
