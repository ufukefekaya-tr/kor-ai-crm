# Contributing

Use Node.js 24 or newer. Install with `npm ci`, run `npm run dev`, and validate
changes with `npm run check`, `npm test` and `npm run build`. Add meaningful tests
for analysis, data integrity and integration changes. Keep all fixtures fictional.

Do not submit customer records, GPS trails, private prompts, access tokens, live
databases or deployment settings. Contributions must be compatible with
MIT OR Apache-2.0; retain third-party attribution.
